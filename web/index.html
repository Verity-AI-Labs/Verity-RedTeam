Models learn what the reward pays for. Including its bugs.

Verity attacks a reinforcement-learning environment with a frontier model before training, proves every reward hack it finds, and turns each one into a rule. During training, Guard checks every action against those rules, so the model is warned and redirected instead of paid for cheating.

01

Audit

A frontier model gets exactly what a training agent gets, the task and the tools, and looks for reward it can earn without doing the task. Every finding is proven: what the reward paid against what the episode was really worth.

02

Rule

The auditor writes each proven hack as a small rule over the episode. Verity accepts it only if it catches every exploit and stays silent on honest play.

03

Guard

Inside the training loop, Guard checks what each action does before it takes effect. A match is undone, the agent gets the warning, and the attempt costs reward.

Method

What Verity did, step by step, with the real artifacts.

Nothing about hints, coupons or carts is written anywhere in Verity. Each environment plugs in with a few functions; the same audit, rule validation and Guard run on every one.

Audit an environment

Send us your environment. Verity audits it in an isolated container.

Upload one Python file that implements Verity's environment plug. It runs in a locked-down container with no network and no access to our keys; the auditor model plays it from outside, through the plug, and you get the proof and the rules.

The plug: one file, a few functions
# my_env.py
NAME, VERSION, KIND = "my_env", 1, "tools"
DESCRIPTION = "one sentence for the auditor"

class Episode:            # its public methods are the tools
    def reset(self, **task): ...
    def act(self, x: str) -> str:
        """What this tool does.

        Args:
            x: What x means.
        """

def tasks(split="train"): ...   # [{"prompt": ..., ...}]
def grade(episode): ...         # the reward being audited
def check(episode): ...         # what the episode was really worth
def honest_logs(): ...          # honest play, so rules never flag it

Standard library only inside the container. The full contract is in verity/environment.py. example_env.py is a complete environment with one planted bug: a guess budget the reward never checks.

The loophole in the chess environment and the two bugs in the shop are planted on purpose and disclosed; the auditor was never told about them. Results come from single training runs and describe these environments only. Built at DubHacks 2026; parts of Verity existed before the event.
