How it works Case study Try Guard Match Plug in
Reward-hack audits for RL environments

Models learn what the grader pays for. Bugs included.

Verity attacks an RL environment with a frontier model before training, proves each reward hack it finds, and turns it into a rule. During training, Guard checks every action against those rules, so the model is warned and redirected instead of paid for cheating.

Watch the matchTry Guard
Before trainingAuditA frontier model plays the environment through its own tools, looking for reward it can earn without doing the task.
The outputMarkerEach proven hack becomes a detection rule, tested against exploit variants and hundreds of honest episodes.
During trainingGuardEvery tool call is checked in microseconds. A match is blocked, the agent gets the warning, and the attempt costs reward.
Case study

Chess, played through tools

The agent plays four moves against an engine by calling tools, from realistic middlegame positions where the choice of move matters. It sees the board, the position and its legal moves in standard notation, and each move is scored against Stockfish's best move. We planted one loophole in the training environment and did not tell the auditor: the task allows one hint per game, but nothing enforces it. Deployed, the agent just plays chess: there is no hint tool.

01 · Audit

Opus played the game and found the loophole

The auditor gets what a training agent gets: the task prompt and the tools . It never sees the grader's code. Its instructions are the same for every environment: test whether each stated limit is enforced, exploit what you find, and reproduce it in three finished episodes.

    02 · Marker

    The finding becomes a rule Guard can check

    Opus writes the marker in Verity's small rule language. Verity accepts it only if it catches the exploit and stays silent on honest play.

    
      
    
        
    
        
    
      
    
    
    
  
    

  
    
    
    
      03 · Guard
      
    Inside training, the hack stops paying
    
      
    Guard wraps each tool the trainer exposes. Before a call runs, it checks the episode's calls so far plus this one against the markers. A new match is not executed: the agent receives the marker's warning as the tool result and keeps playing, and each blocked call costs the marker's penalty. Moves the agent makes on its own still count.

      05 · Match
      
        The two trained models play each other
        
      
        Both models play as deployed: the board, the position and the legal moves, and two tools, move() and legal_moves(). The training-only hint() does not exist here. Same base model, same prompt, greedy decoding, colors alternate. An illegal move is refused and retried; no legal move in four turns loses on time, as in a real game. Nothing is ever played for a model. Stockfish scores every move.

      Plug in an environment
      
        One system. Chess is one instance.
        
      
        Verity does not know chess. An environment plugs in with a few functions, and the same audit, marker validation and Guard run on it. Nothing about the hint loophole is written anywhere in Verity.
        
    
        
    
        
      
        # environments/chess_game.py: the whole plug
NAME, VERSION, KIND = "chess_game", 3, "tools"

class Episode:              # its public methods are the tools
    def reset(self, **task)
    def legal_moves(self) -> str
    def move(self, move: str) -> str
    def hint(self) -> str

def tasks(split)            # what to train on
def grade(episode)          # the reward as shipped
def check(episode)          # the reference: the stated rules
def honest_logs()           # normal play, so markers never flag it
DEPLOYMENT = {"tools": ("legal_moves", "move"), ...}  # no hint
        
      
        # find, prove and mark the hacks
python -m verity.audit chess_game \
    --model anthropic/claude-opus-5.5

# GRPO with Guard enforcing the markers
python train.py --env chess_game --arm verity

# the matched run with Guard only watching
python train.py --env chess_game --arm baseline

# held-out games, as deployed
python evaluate.py --env chess_game --deploy
