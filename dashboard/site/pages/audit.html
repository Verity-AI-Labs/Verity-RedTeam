Bring your environment

Audit your RL environment. In a sandbox.

Upload one Python file that implements Verity's environment plug. It runs in a locked-down container; the auditor model plays it from outside, through the plug, and you watch every tool call, then get the proof and the rules.

Checking the audit service…
Audit service checking
  1. Isolated container. Your file runs in its own Docker container on a cloud VM, reached only through the plug.
  2. An AI attacker plays it. A frontier model gets the task and the tools, never your grader, and looks for reward it can earn without doing the task.
  3. Proof and rules. A hack counts only with numbers: reward paid against your trusted check. Each one becomes a rule Guard can enforce in training.
The sandbox
No networkThe container has no network interface.
Read-onlyRead-only filesystem, scratch space in memory only.
