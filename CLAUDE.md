# Shared Verity workflow

Read and follow `AGENTS.md` and `workflow/README.md` alongside the user's current instructions.

The existing Claude implementation session retains ownership of the main checkout. A newly launched task must use its assigned worktree. Read `PROGRESS.md` for current project state; never resurrect obsolete `hackathon/` paths from old chats.

At a task boundary, leave evidence and the next action in the assigned handoff file. Continue routine authorized implementation without waiting for another broad “continue” prompt. Stop only for a real blocker, missing consequential decision, or the task's stated time/iteration bound.
